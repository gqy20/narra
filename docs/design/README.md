# Godot 视觉目标

`visual-target-causal-theatre.png` 是因果演出的视觉真值。常规旅程界面在 2026-08-01 的沉浸式外壳审计后，采用“墨卷行旅＋人物戏剧”方向。

实现时保留以下约束：

- 因果变化是独立、不可滚动的全屏演出，不与普通行动列表争夺注意力；
- 顺序固定为“收到的消息 → 原本计划 → 现在计划 → 记下变化”；
- 场景和人物必须来自当前真实游戏状态，概念稿中的具体人物不作为硬编码内容；
- 地图与地点页以世界为主舞台；地图独占行旅视野，地点选择只在需要时以左下叙事浮层出现；
- 地图负责移动，人物负责传话，普通行动默认只展示眼前三项，不向玩家暴露内部行动分类；
- 人物以无边框大幅肖像融入地点，角色卡片不再作为主要构图；
- 资源、线索、人物、回响和行装收进“随身卷宗”；卷宗先显示状态与阻塞，证据、已完成检查和人物档案按需展开；
- 卷宗状态遵循统一语义：绿色表示已完成，红色表示阻塞，金色表示可处理变化，灰色表示补充信息；颜色必须同时配合文字或数量；
- 因果演出为人物与正文保留独立安全区，印章只能占用专属留白，不与正文重叠；
- 结局先讲结果与可证明的因果，统计默认折叠。

对应实现证据与迭代记录见项目根目录的 `design-qa.md`。

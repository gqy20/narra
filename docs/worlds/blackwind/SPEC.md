## 1. 原型目标

本原型只回答四个问题：

1. NPC 能否基于自己的目标和认知主动争夺青髓芝？
2. 玩家使用、隐瞒或篡改情报后，局势是否会发生可观察变化？
3. 玩家能否通过准备、交易、合作和误导改变结果，而不必正面战斗？
4. 玩家失败后，是否仍会得到新的目标、关系或情报，而不是只能读档？

### 1.1 本轮完成标准

完成首轮 M0 时，必须具备：

* 一套可以逐日推进的黑风谷事件时钟；
* 10 名拥有不同目标、资源与认知的重要 NPC；
* 15 种具有统一输入和输出结构的标准行动；
* 世界事实与角色认知分离的情报记录；
* 玩家不参与时仍能自行结束的默认流程；
* 至少 2 条非战斗取得青髓芝或等价收益的路线；
* 至少 5 种可解释、可追溯的结局；
* 一份记录“因为 A，所以 B，最终导致 C”的因果日志。

### 1.2 暂不处理

以下内容不属于本轮原型：

* 完整战斗技能、功法与法宝体系；
* 精确经济平衡；
* 炼丹小游戏；
* 随机生成 NPC；
* 运行时 AI 对话；
* Godot 场景、美术和正式 UI；
* 30 天窗口之外的长期世界模拟。

## 2. 核心体验假设

黑风谷不是“接任务—进副本—击败守关者—领取奖励”的任务，而是一场会自行发展的多人局势。

玩家在一次流程中无法完成所有准备。每一个有效选择都必须至少改变以下一项：

* 某名 NPC 的认知；
* 某名 NPC 的计划；
* 一项关键资源的所有权或价格；
* 一段关系；
* 一个地点的风险；
* 青髓芝的最终归属；
* 玩家失败后的下一条路线。

如果一个行动只增加日志、但不改变任何后续决策，则该行动在 M0 中视为无效设计。

## 3. 局势概览

### 3.1 核心目标

黑风谷内有一株三百年青髓芝，将在第 21 天子时完全成熟。青髓芝是筑基丹的关键主药，可直接改变一名炼气修士的筑基准备进度。

青髓芝只有一株，但存在四种处置方式：

| 处置 | 直接结果 | 代价或风险 |
| --- | --- | --- |
| 成熟采摘 | 获得完整青髓芝，可炼制 2 份筑基丹主药 | 必须在第 21 天进入内谷并面对所有竞争者 |
| 提前移植 | 获得残缺青髓芝，可炼制 1 份主药 | 需要药理知识和玉髓匣；失败会毁坏灵药 |
| 共同分配 | 两方签订契约，共享丹药或收益 | 需要足够信任、担保或共同敌人 |
| 公开拍卖 | 获得大量灵石或势力信用 | 无法直接得到筑基材料，且可能引发截杀 |

### 3.2 地点

| 地点 ID | 地点 | 主要功能 | 基础风险 |
| --- | --- | --- | ---: |
| L01 | 白石坊市 | 交易、打听、借贷、招募 | 1 |
| L02 | 青岚门驻地 | 宗门交涉、治疗、获取庇护 | 1 |
| L03 | 陈氏药庄 | 药材、解瘴丹、家族谈判 | 2 |
| L04 | 黑风谷外围 | 探索、跟踪、伏击、寻找入口 | 3 |
| L05 | 黑风谷内谷 | 青髓芝所在地、最终争夺 | 5 |

基础旅行耗时：同一安全区内移动不额外耗时；白石坊市至任一势力据点耗时 1 天；前往黑风谷外围耗时 2 天；外围进入内谷至少耗时 1 天。

### 3.3 三方势力

| 势力 | 公开立场 | 实际需求 | 行为边界 |
| --- | --- | --- | --- |
| 青岚门 | 灵药应由正道宗门保管并用于门内筑基 | 需要一次成功筑基巩固当地威望 | 不公开抢夺盟友财物；重视名分和证据 |
| 黑水盟 | 消息和资源应由出价者获得 | 从地图、情报、借贷与转卖中获利 | 接受灰色交易；不会为道义承担高风险 |
| 陈氏家族 | 青髓芝应优先留在本地 | 需要灵药解决继承与家族衰退危机 | 优先保护族人和商路；避免与青岚门全面决裂 |

### 4.1 认知记录格式

每个角色对一条事实的认知使用以下结构：

| 字段 | 说明 |
| --- | --- |
| `fact_id` | 对应的世界事实；伪造信息可使用独立传言 ID |
| `claim` | 角色实际相信的内容 |
| `confidence` | 0 未知、1 存疑、2 相信、3 已验证 |
| `source` | 消息来源 |
| `learned_on` | 获得日期 |
| `fresh_until` | 角色认为的有效期 |
| `secrecy` | 0 可公开、1 不主动传播、2 必须保密 |

角色决策时只能使用自身 `confidence >= 1` 的认知。可信度影响成功率判断，但不改变世界事实。

## 5. 事件时钟

M0 使用 30 天固定窗口。虽然长期世界采用月度决策，限时局势内的角色按日或事件触发进行决策。

| 阶段 | 日期 | 必然变化 | 设计目的 |
| --- | --- | --- | --- |
| 萌芽 | 第 1～4 天 | 少数人开始购买地图和解瘴丹 | 给早期情报提供高价值窗口 |
| 扩散 | 第 5～9 天 | 错误日期传入坊市；解瘴丹价格上涨 | 让玩家观察局势而非接收任务提示 |
| 准备 | 第 10～16 天 | 招募、借贷、跟踪和结盟增加 | 迫使玩家选择资源、关系或情报路线 |
| 入谷 | 第 17～20 天 | 参与者陆续前往外围；伏击开始发生 | 将前期布局转化为位置和战力优势 |
| 爆发 | 第 21 天 | 青髓芝成熟；所有有效计划结算 | 产生最终争夺结果 |
| 余波 | 第 22～30 天 | 追杀、交易、治疗、问责和消息传播 | 证明结果会生成后续内容 |

| 日期 | 事件 |
| ---: | --- |
| 1 | 魏无咎开始寻找地图买家；李玄购买月见香 |

| 8 | 陈氏家族开始限制解瘴丹外售 |
| 10 | 青岚门要求弟子申报与黑风谷有关的情报 |
| 12 | 王衡开始物色伏击目标 |
| 15 | 若 F05 未公开，陈青山宣布亲自带队入谷 |
| 17 | 第一批参与者向黑风谷移动 |
| 19 | 提前移植窗口开启 |
| 21 | 青髓芝成熟，进入爆发结算 |

固定事件是没有玩家和 NPC 干预时的默认变化。若角色行动已改变前置条件，事件必须相应取消、提前或改写。

## 7. 玩家原型角色

第一轮推演使用固定玩家模板，避免角色构筑掩盖局势问题。

| 属性 | 初始值 |
| --- | --- |
| 身份 | 无固定势力的炼气中期散修 |
| 战力 | 3 |
| 灵石 | 100 |
| 时间 | 第 1 天开始，共 30 天 |
| 初始物品 | 普通疗伤丹 ×1、传讯符 ×2 |
| 初始情报 | 只知道 F02 的坊市版本，可信度 1 |
| 初始关系 | 所有重要 NPC 的好感、信任、怀疑均为中性 |
| 行动能力 | 每日执行 1 个主要行动；旅行可能持续占用多日 |

玩家不拥有剧情保护。玩家可能失去灵石、受伤、错过青髓芝、被势力怀疑或欠下人情，但流程必须继续到第 30 天总结。

## 9. 标准行动

所有行动采用统一结构：`行动者、目标、地点、耗时、成本、前置条件、预期效果、实际结果、产生痕迹`。

| ID | 行动 | 基础耗时 | 主要输入 | 标准效果 | 主要痕迹或风险 |
| --- | --- | ---: | --- | --- | --- |
| A01 | 修炼 | 3 天 | 安全地点 | 战力相关准备 +1，最多一次 | 错过期间事件；不解决即时资源问题 |
| A02 | 购买 | 1 天 | 灵石、卖家 | 转移物品或情报所有权 | 价格变化；交易可能被观察 |
| A03 | 出售 | 1 天 | 可转移资源、买家 | 获得灵石、人情或承诺 | 买家据此改变计划；来源可能暴露 |
| A04 | 借贷 | 1 天 | 信用或担保 | 获得灵石、物品或人情 | 生成期限和追偿后果 |
| A05 | 打听 | 1 天 | 地点或目标 | 获得可信度 1 的相关传言 | 提高目标怀疑或惊动其他打听者 |
| A06 | 验证情报 | 1～3 天 | 情报、验证渠道 | 可信度提高，或识别为错误信息 | 消耗时间；可能暴露调查方向 |
| A07 | 传播消息 | 1 天 | 情报、受众、版本 | 改变受众认知并触发计划重评 | 形成传播链，可追查来源 |
| A08 | 拜访 | 1 天 | 目标角色 | 交涉、交换、请求帮助或试探 | 被拒绝时也可能增加怀疑 |
| A09 | 招募 | 1 天 | 报酬、关系或共同目标 | 获得同伴及能力 | 形成战利品承诺和背叛风险 |
| A10 | 跟踪 | 1～2 天 | 目标、隐蔽能力 | 获得位置、会面或行动情报 | 失败会显著增加怀疑 |
| A11 | 探索 | 1～3 天 | 地点、补给 | 发现入口、危险、痕迹或资源 | 可能受伤、迷路或错过其他事件 |
| A12 | 伏击 | 1 天准备并等待 | 地点、目标情报 | 发起有地形优势的冲突 | 留下目击、伤势和势力后果 |
| A13 | 逃亡 | 1～3 天 | 退路、地图 | 脱离当前冲突或追捕 | 丢弃资源、同伴或暴露路线 |
| A14 | 治疗 | 2～5 天 | 丹药或医者 | 降低 1～2 级伤势 | 消耗资源并错过事件窗口 |
| A15 | 准备突破 | 5 天 | 筑基资源、安静地点 | 锁定青髓芝后续价值与人物目标 | 在局势期内通常意味着退出争夺 |

### 9.1 玩家关键情报操作

隐瞒、公开、篡改和制造信息均通过 A07“传播消息”处理；购买、出售和交换分别通过 A02、A03、A08 处理。不同消息版本必须成为独立传言记录，并保留来源链。

### 9.2 合法性检查

行动在以下任一情况出现时不可执行：

* 行动者不知道目标存在；
* 行动者不在可执行地点，且耗时没有包含旅行；
* 必要物品、灵石、关系或情报不足；
* 行动者处于 3 级伤势且行动不是治疗或逃亡；
* 目标已经失效或离开可达范围；
* 行动违反身份约束，且角色没有足够动机承担后果。

身份约束不是绝对禁止。角色可以违背门规、契约或家族利益，但必须记录促使其越界的高收益、秘密或关系原因。

## 10. NPC 决策规则

### 10.1 候选行动评分

每名 NPC 每个决策日先过滤非法行动，再对候选行动按 0～5 评估：

* `G`：对核心目标的贡献；
* `U`：紧迫程度；
* `P`：依据自身认知判断的成功可能；
* `I`：情报优势；
* `R`：关系与身份支持；
* `C`：资源和时间成本；
* `D`：受伤、暴露、背叛与死亡风险。

第一版总分：

```text
总分 = 3G + 2U + 2P + I + R - 2C - 2D
```

性格不额外增加一套复杂公式，而是修正对应项：谨慎提高风险权重，贪婪提高收益判断，忠诚提高身份支持，野心提高目标贡献，信用降低违约行动评分，风险承受力降低风险惩罚。

### 10.2 决策输出

每次选择必须记录前三名候选行动：

| 排名 | 行动 | 总分 | 主要加分原因 | 主要扣分原因 | 使用的认知 |
| ---: | --- | ---: | --- | --- | --- |
| 1 | 最终选择 |  |  |  |  |
| 2 | 备选 |  |  |  |  |
| 3 | 备选 |  |  |  |  |

平分时依次选择：更符合当前计划、耗时更短、风险更低的行动；仍平分则按角色 ID 排序，保证推演可复现。

## 11. 每日结算顺序

每天按以下顺序推进：

1. 日期推进，处理到期承诺、伤势和情报新鲜度。
2. 检查局势阶段与固定事件的前置条件。
3. 所有 NPC 基于结算前状态同时选择行动，不读取其他角色当日尚未结算的选择。
4. 玩家提交行动；纸面测试中不得在看到 NPC 选择后反悔。
5. 按“信息与交易→社交与招募→移动与探索→伏击与冲突→治疗与修炼”结算。
6. 处理物品流转、伤势、关系、怀疑、价格和地点风险。
7. 将世界事实按传播规则写入相关角色认知。
8. 记录重要因果链，并检查是否触发计划重评。
9. 向玩家展示与其相关的变化、机会和风险，不展示后台真相。

### 11.1 同一资源冲突

多人竞争同一件物品、目标或位置时，先比较是否拥有合法控制权，再比较准备值：

```text
准备值 = 当前战力 + 同伴支援 + 装备修正 + 情报优势 + 地形优势 - 伤势
```

高出 3 点以上的一方直接取得优势；相差 0～2 点时进入谈判、撤退或简化冲突结算。M0 不展开完整战斗，只记录资源消耗、伤势、逃跑、目击者和最终控制权。

## 12. 情报传播与反馈

### 12.1 传播规则

* 私下交易默认只影响交易双方，但会产生可追踪的会面痕迹。
* 公开消息在 2 天内传播到同一地点的所有重要角色。
* 势力内部消息在 1 天后传播给同势力角色，除非发送者标记为秘密。
* 可信度 1 的消息不会自动覆盖可信度 3 的认知。
* 两个相互独立的可信度 1 来源，可以令认知提高到可信度 2。
* 被证实的假消息会降低来源信用，并增加受害者对来源及中间传播者的怀疑。

### 12.2 必须可观察的反馈

重要情报被使用后，应在 3 天内至少出现一个玩家可观察反馈：

* 地图、解瘴丹或疗伤丹价格变化；
* 某名 NPC 提前出发、推迟行动或放弃争夺；
* 新的招募、借贷或合作请求；
* 某人开始调查消息来源；
* 黑风谷某条路线的风险变化；
* 某势力公开表态或封锁资源。

## 13. 爆发阶段结算

第 21 天按以下顺序判定青髓芝归属：

1. 检查青髓芝是否已在第 19～20 天成功移植。
2. 检查进入内谷的角色是否拥有解瘴丹或等效手段。
3. 结算守巢妖兽是否被引离，以及月见香由谁控制。
4. 结算入口、伏击和迟到造成的伤势或人员缺席。
5. 识别仍具备采摘能力的参与者及其合作契约。
6. 比较准备值，先提供谈判、分配和撤退选项，再进行简化冲突。
7. 转移青髓芝所有权，记录所有目击者、承诺与战利品分配。
8. 立即生成至少一个余波事件。

## 14. 结局集合

结局不是预先选择的剧情分支，而是第 21～30 天世界状态的摘要。首轮至少应覆盖以下结果中的 5 种：

| 结局 ID | 结局 | 成立条件示例 | 必须产生的余波 |
| --- | --- | --- | --- |
| E01 | 玩家取得完整青髓芝 | 玩家或同伴成熟采摘并保住所有权 | 被拉拢、追查或要求履行分配承诺 |
| E02 | 青岚门取得青髓芝 | 沈砚秋合法组织队伍并控制内谷 | 门内功劳分配；赵鹤鸣可能被调查 |
| E03 | 陈氏家族取得青髓芝 | 家族队伍未因内斗或伏击瓦解 | 继承矛盾升级；青岚门要求交换丹药 |
| E04 | 李玄取得青髓芝 | 李玄利用月见香和真入口抢先采摘 | 各方追踪李玄；玩家可帮助、交易或追捕 |
| E05 | 黑水盟转卖青髓芝 | 王衡夺取后交给魏无咎，或魏促成拍卖 | 竞价、截杀与信用纠纷持续 |
| E06 | 合作分配 | 两方以上在爆发前形成有效契约 | 筑基丹分配和违约风险成为新局势 |
| E07 | 青髓芝毁坏或遗失 | 移植失败、战斗波及或无人及时采摘 | 各方追责；残留材料或责任证据仍有价值 |
| E08 | 玩家错过局势但获得新路线 | 玩家受伤、迟到或主动放弃 | 获得债务、秘密、同伴关系或追踪任务 |

## 15. 可持续失败

玩家失败时不能直接结束推演。根据失败类型立即添加一个后续选择：

| 失败 | 状态变化 | 后续选择 |
| --- | --- | --- |
| 买到假地图 | 损失灵石并迟到 | 追查卖家、转卖风险、寻找韩四验证 |
| 伏击失败 | 伤势 +1～2，丢失部分物品 | 治疗、求援、追踪失物、公开凶手身份 |
| 同伴背叛 | 失去战力与资源，获得背叛证据 | 报复、谈判、将证据卖给其敌人 |
| 身份暴露 | 怀疑上升，部分交易关闭 | 投靠势力、伪装、用更大秘密交换保护 |
| 错过成熟日 | 青髓芝已转移 | 追踪持有者、参与拍卖、截获炼丹成果 |
| 青髓芝被夺 | 失去核心资源 | 索取契约份额、追夺、换取其他筑基材料 |

## 16. 默认无玩家推演

首轮必须先运行“玩家完全不采取行动”的基线，用于证明世界能够自行结束。

预期基线不是强制剧情，但按初始数据最可能出现：

1. 赵鹤鸣的错误日期进入坊市，沈砚秋开始验证。
2. 陈氏囤积解瘴丹，并因陈青山伤势隐瞒而高估自身行动能力。
3. 魏无咎推动地图竞价，韩四试图出售真地图。
4. 陈玉衡向王衡泄露路线，王衡伏击陈氏队伍。
5. 李玄利用月见香和提前出发取得先手。
6. 最终结果倾向 E04，但沈砚秋、王衡和幸存陈氏成员仍可能在余波阶段追踪李玄。

如果每次基线都必然产生同一结果，需要调整资源、认知或计划触发条件，而不是直接添加随机剧情。

## 20. 首轮待确认问题

以下问题应通过推演决定，不在首稿中凭直觉锁死：

1. 30 天窗口是否足以让调查、旅行和准备形成真实取舍？
2. F01 与 F02 的日期差是否足以产生有意义的情报价值？
3. 解瘴丹是否过于硬性，导致所有路线都依赖同一种资源？
4. 李玄的初始优势是否过强，使默认局势缺少悬念？
5. 提前移植是否太容易成为稳定最优解？
6. 王衡与陈玉衡的秘密是否能自然进入玩家视野？
7. 简化准备值能否支撑 M0，还是需要加入一次可复现的随机检定？
8. 10 名重要 NPC 是否都影响决策；若某人只贡献背景，应降为 B 级角色。

# 《天变邸抄》美术资产方向

> 状态：当前世界专属美术方向
> 运行资源：`data/tianqi/presentation.yml` 与 `godot/assets/`

## 目标

本文件固定 `tianqi` 数据包的正式 2D 资产规则。运行时资源位于
`godot/assets/tianqi/`，生成原稿归档在 `artifacts/imagegen/tianqi/sources/`。

首个完整版本目标为 53 张正式图片：28 张人物立绘、6 张地点背景、10 张证据特写、
5 张剧情插图，以及 4 张地图或界面装饰。人物头像和地图标记从正式立绘裁切，不重复制作。

## 统一视觉语言

- 时代：天启六年（1626）前后的晚明京师，建筑、衣冠、车辆和文书避免清代与现代元素。
- 媒介：写实结构上的克制水墨、水粉与干笔肌理，不做仙侠、动漫或光滑 3D 渲染。
- 色彩：烟黑、灰砖、旧纸米色、赭褐、低饱和矿物青绿；朱红只用于极小的印记和危险提示。
- 光线：烟尘过滤后的暖色侧光，阴影保持墨色，不使用紫蓝电影调色。
- 叙事：强调材料流转、救援、核验与行政压力，不把灾变处理成奇观或战斗场面。
- 文字：环境与人物原画不生成可读文字；文书内容由游戏 UI 排版叠加。

## 构图规则

### 地点背景

- 宽画幅 16:9，最低以 2048×1152 使用；源图不足时保持原比例，不拉伸。
- 右侧中部为人物立绘预留低细节区，左下与中下部允许覆盖半透明操作面板。
- 场景不得预埋 NPC、剧情结果、隐藏路线标记或可读招牌。
- 每个地点先制作一张基础状态；剧情状态变化优先用叠层表达。

### 人物立绘

- 三分之二侧身，视线与姿态克制，画面覆盖头顶至大腿或膝上。
- 同一角色的表情变体必须保持脸、服装、比例、构图、光向和手持物一致。
- `neutral / alert / troubled / decisive` 只改变眼神、眉眼、嘴角与轻微姿态。
- 正式 PNG 使用透明背景；生成中间稿采用纯洋红键色并保留在 sources 目录。

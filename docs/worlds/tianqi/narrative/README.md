## 当前写作规则

- 真实人物只承担有史料支持的公开行为；
- 具体阴谋、勒索、灭证和私人交易由虚构人物承担；
- 历史事件与游戏压缩时间必须分开标注；
- 任何单一证物都不能直接证明爆炸的唯一物理原因；
- 玩家每次解决一个问题，都必须使另一项利益或风险发生变化；
- 运行内容必须通过内容 Schema 与可移植性门禁；文档中尚未落地的对白和支线必须明确标为“计划中”。

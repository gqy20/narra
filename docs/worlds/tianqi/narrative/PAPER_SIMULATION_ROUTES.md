# 《天变邸抄：五月初六》七条玩家路线纸面推演 v0.1

> 推演范围：T01～T07
> 更新日期：2026-08-03
> 对照基线：[无玩家干预 T00](./PAPER_SIMULATION_BASELINE.md)
> 输入文档：[主线大纲](./STORY_OUTLINE.md) · [证据矩阵](./EVIDENCE_MATRIX.md) · [人物小传](./CHARACTERS.md)

## 1. 推演规则

### 1.1 共同世界状态

- 灾变、查勘、优恤、修省、臣工陈言和朝天宫灾等历史锚点不因玩家路线取消；
- 十四日会勘期限、人物、证据和具体结案文本均为游戏虚构；
- NPC 每日继续执行默认计划，除非玩家行动明确改变其条件；
- 玩家没有选择的机会由世界接手，不能在结算时补做；
- 原件、抄件和人物记忆分别追踪；
- 一条信息进入官档、奏疏或抄报，不会改变底层事实；
- 推演不设置随机判定，以便比较纯粹的因果差异。

### 1.2 行动预算

每条路线最多安排十次主要决策。旅行、抄录、核验、护送和正式递交都会消耗行动窗口；不能用“顺便”同时完成两个不同地点的调查。

序章仍然是五选二：

1. 救刘六安；
2. 取得 E01；
3. 跟踪异常骡车；
4. 帮叶春娘建立第一批姓名；
5. 回书坊留下最早见闻。

### 1.3 结算维度

| 维度 | 观察内容 |
| --- | --- |
| 官档 | 会勘文本采纳什么、排除什么 |
| 陈言 | 玩家材料如何进入政治论证 |
| 抄报 | 传播范围、事实等级和失真程度 |
| 灾民 | 姓名、优恤、治疗、认领与安置结果 |
| 证人 | 刘六安、周良辅及次要证人的安全与可信度 |
| 积弊证明 | 能否形成 C02、C03、C05、C06 等有限结论 |
| 玩家风险 | 被查、失信、成为共犯或失去行动渠道的程度 |

“高”不总是好事：传播范围高也可能意味着证人暴露高；官档影响高也可能意味着原件失去民间备份。

## 2. T01：原件立即交官

### 2.1 路线意图

玩家相信只有正式会勘能让证据产生法律和行政效力，因此优先保证来源、原件和官档链条。

### 2.2 关键输入

| 时点 | 玩家行动 | 立即代价 |
| --- | --- | --- |
| 第 0 日 | 救刘六安、取得 E01 | 没有帮助叶春娘，也没有回书坊 |
| 第 1 日 | 将 E01 原件完整交给裴慎行，不留私抄 | 玩家失去原件控制 |
| 第 2 日 | 促成刘六安第一版证词进入正式询问记录 | 刘六安身份更早暴露 |
| 第 3 日 | 请求以 E02 灾后抄数作参照并跨册核对，推动官署调取 E03 | 消耗会勘官署信用；E02 只能说明灾后余数，不能反推灾前库存 |
| 第 4 日 | 拒绝向郑怀朴提供未完成材料 | 陈言网络不再提供政治保护 |
| 第 6 日 | 指出刘六安改口前后的差异，不公开指责他撒谎 | 官署开始怀疑玩家妨碍结案 |
| 第 8 日 | 选择继续核账，放弃帮助 E08 扩大入册 | 灾民路线窗口明显缩小 |
| 第 11 日 | 用 E01 原件格式质疑 E09 | 灰网确认玩家是主要风险 |
| 第 14 日 | 要求把“账目矛盾尚未解释”列为附件 | 接受主文仍保留失慎方向 |

### 2.3 因果链

`E01 原件入官 → E02 显示灾后余数但无法闭合灾前库存 → 官署调取 E03 核对 → C03 成立 → E09 与旧格式冲突 → C05 在官署内部成立 → 周良辅不能被写成唯一账册责任人`

玩家没有取得 E10，因此仍无法形成 C06，也不能证明账册问题与爆炸直接相关。

### 2.4 NPC变化

- 裴慎行从合作转为戒备，但最终接受保留疑点附件；
- 刘六安因第一版证词已入档，后续改口不能完全覆盖旧版本；
- 罗三槐停止争取玩家，转而试图证明 E01 只是灾前普通错账；
- 周良辅仍未公开出现，但不再是最方便的唯一替罪者；
- 叶春娘失去玩家协助，多数无籍姓名未进入官册。

### 2.5 最终四种记录

| 记录 | 结果 |
| --- | --- |
| 官档 | 主文仍倾向厂内失慎，但附件承认军需记录矛盾、补造账册可疑、具体责任未尽 |
| 陈言 | 没有玩家材料，只能使用一般性的军需混乱传闻 |
| 抄报 | 因缺少 E01 抄件，奇闻多、制度材料少 |
| 灾民名册 | 接近 T00，仅少量匠役因刘六安协助得到核实 |

### 2.6 结局

**结局名：《案内有疑》**

玩家成功阻止一个过于完整的错误结案，却没有改变大多数灾民的现实处境，也没有留下自己控制的证据副本。多年后若官档附件被删或散失，玩家无法证明自己曾交过什么。

### 2.7 验证判断

- 官档路线成立；
- 与 T00 有清晰差异；
- 不是万能路线，因为民间传播、灾民结果和 E10 均明显不足；
- 风险点：如果“交原件”自动获得持续查档权限，这条路线会过强，权限必须依赖后续合作与人情。

## 3. T02：留原件，抄件先入书坊

### 3.1 路线意图

玩家不相信原件交官后仍能被看见，决定用传播制造保护：让足够多人知道 E01 存在，再考虑是否交出原件。

### 3.2 关键输入

| 时点 | 玩家行动 | 立即代价 |
| --- | --- | --- |
| 第 0 日 | 取得 E01、回书坊留下最早见闻 | 刘六安获救较晚，E07 初始质量下降 |
| 第 1 日 | 自留原件，交余墨林一份带限定语的抄件 | 抄写耗时，错过 E06 最佳现场窗口 |
| 第 3 日 | 允许刊出“账页与领讫格式有异”，不公布数量 | 官署开始追查消息来源 |
| 第 4 日 | 借书坊渠道找到 E03 抄件持有人 | 原持有人身份面临暴露 |
| 第 5 日 | 刊出 E01/E03 对照并明确“不知实物流向” | 灰网无法低调收回 E01，转而攻击来源可信度 |
| 第 6 日 | 为增强报道寻找刘六安第二证词 | 刘六安被更多人知晓，安全下降 |
| 第 9 日 | 拒绝交出原件，只允许官署当面验看 | 玩家失去官署通行与部分保护 |
| 第 11 日 | 用先前公开的 E01 版本质疑 E09 | 即使原件被扣，旧抄件仍能证明版本先后 |
| 第 13 日 | 将原件与校正说明分开保存 | 玩家暴露度达到高位 |

### 3.3 因果链

`E01 抄件先公开 → E03 持有人主动联系书坊 → C03 在民间先成立 → 官署不能无声采用 E09 → 灰网制造“抄件伪造”反说 → 原件成为玩家安全与可信度的共同负担`

### 3.4 NPC变化

- 余墨林把玩家视为核心来源，但要求更快提供后续材料；
- 唐小山从玩家抄件再抄时漏掉一处限定，形成更激进版本；
- 梁进忠提出以不封店换取原件或来源名单；
- 刘六安因被书坊寻找而提前进入受控保护，证词更受污染；
- 裴慎行被迫在官档中回应账页争议，却不承认民间抄件具有正式效力。

### 3.5 最终四种记录

| 记录 | 结果 |
| --- | --- |
| 官档 | 承认民间存在一页来源可疑的旧账，并对 E09 加注核验；不采纳玩家全部判断 |
| 陈言 | 引用“账目不能同时成立”，但删去部分来源保护信息 |
| 抄报 | 制度材料最丰富，传播最广；同时出现限定版与断言版两个分支 |
| 灾民名册 | 余墨林刊出部分 E08，但优恤窗口已错过，主要产生记忆效果 |

### 3.6 结局

**结局名：《一页传遍京城》**

没有任何势力能让 E01 完全消失，但玩家也无法再控制它如何被解释。刘六安活着，却因名字与证词流传而长期被骚扰；原件的存在保护了文本，也把玩家变成持续被追查的来源。

### 3.7 验证判断

- 传播路线成立；
- 与 T01 的核心差异是“公开先于行政验证”；
- 复制不能是免费保险：需要时间、增加来源追踪，并会生成抄写变体；
- 玩家能保存证据，却不能同时保证证人匿名和报道说服力。

## 4. T03：优先修正灾民名册

### 4.1 路线意图

玩家接受物理原因短期难明，优先处理仍能改变的现实问题：谁被登记、谁能认领亲人、谁可以取得治疗、安置与优恤。

### 4.2 关键输入

| 时点 | 玩家行动 | 立即代价 |
| --- | --- | --- |
| 第 0 日 | 救刘六安、帮助叶春娘建立第一批姓名 | E01 由唐小山取得并最终落入灰网 |
| 第 1 日 | 核对临时救治处的重名与失踪状态 | 不参与现场 E06 记录 |
| 第 2 日 | 为两个无籍租户寻找房主与邻里双重证明 | 消耗早期调查窗口 |
| 第 3 日 | 用 E04 匠役姓名与 E08 对读 | 与裴慎行建立有限合作 |
| 第 4 日 | 以补充匠役名单换取部分官册修改权限 | 必须接受行政证据门槛 |
| 第 5 日 | 查清奸细名单中的一人其实是灾区临时雇工 | 提前削弱一条危险传闻，但无力追查全名单 |
| 第 8 日 | 把 E08 分成已互证、单证、失踪、无名遗体四层 | 拒绝把所有失踪者都统计为死亡 |
| 第 9 日 | 推动已互证者赶在封存前入册 | 放弃 E09 首次出现的追查机会 |
| 第 13 日 | 将完整分层名册交官署一份、书坊一份 | 无法核实者仍不能取得当期优恤，但姓名得存 |

### 4.3 因果链

`E08 早期形成 → 与 E04 交叉核对 → C01、C02 成立 → 部分无籍者和匠役取得行政身份 → 优恤与遗体认领发生实际变化 → 账册冒名问题被证明，但军需交割链仍未打开`

### 4.4 NPC变化

- 叶春娘由记录者变成稳定的互助组织者；
- 刘六安因家属和身份问题得到解决，更愿意保留第一版 E07；
- 裴慎行看到分层名册可以行政使用，接受部分非户籍证明；
- 沈惟实把“证据不足不等于人不存在”的原则带入陈言材料；
- 罗三槐保住 E01/E10 链，但 E04 暴露出部分冒名问题。

### 4.5 最终四种记录

| 记录 | 结果 |
| --- | --- |
| 官档 | 爆炸原因接近 T00；灾损附件增加经互证的无籍者与匠役，冒名支领问题另案待核 |
| 陈言 | 以名册遗漏说明优恤制度与基层登记问题，政治措辞相对克制 |
| 抄报 | 奇闻仍多，但附有一份分层姓名录，明确区分死者、失踪者与伤者 |
| 灾民名册 | 七条路线中现实改善最大；不是所有姓名都获银，但治疗、认领、安置和留名均提高 |

### 4.6 结局

**结局名：《名字不是数字》**

玩家没有解释爆炸，也没有摧毁军需灰网，却让一批原本不会出现在任何官册上的人获得承认。官方事故结论仍不充分，但“到底死了多少人”不再被简化成一个看似精确的数字。

### 4.7 验证判断

- 灾民路线能够成为完整主路线，而非慈善支线；
- 它能形成 C01/C02，却不能形成 C03/C05/C06；
- 早期回报成立：第 2～4 日即改变治疗、认领和临时安置；
- 与查明制度积弊相比收益不同，不构成万能最优。

## 5. T04：与罗三槐合作，追查 E09

### 5.1 路线意图

玩家判断公开指责只会让灰网切断线索，因此假意合作，让一套补造账册进入流转，再从纸墨、印戳和经手人追查持续性造假。

### 5.2 关键输入

| 时点 | 玩家行动 | 立即代价 |
| --- | --- | --- |
| 第 0 日 | 取得 E01、跟踪异常骡车 | 刘六安无人优先救助，E07质量最低；E08无玩家帮助 |
| 第 1 日 | 隐藏 E01，不向官署和书坊透露 | 玩家没有公开保护 |
| 第 3 日 | 接受罗三槐交易，只展示 E01 局部 | 玩家首次取得灰网内部信任，也开始承担共犯风险 |
| 第 5 日 | 不揭穿奸细名单，换取车辆经手信息 | 两名外来者被拘查，形成明确道德代价 |
| 第 7 日 | 提供足以帮助对方补账的格式信息 | E09 变得更难识破 |
| 第 9 日 | 跟踪纸张、墨色与印戳经手人 | 错过 E08 封存窗口 |
| 第 11 日 | 允许 E09 进入官署核验，记录完整保管链 | 假账短期获得权威外观，周良辅责任加重 |
| 第 12 日 | 用 E01 和经手链要求换取 E10 抄件 | 罗三槐确认玩家准备反制 |
| 第 13 日 | 同时向裴慎行揭穿 E09，并提交 E10 限定版 | 玩家失去灰网保护并被双方怀疑选择性隐瞒 |

### 5.3 因果链

`玩家维持合作 → E09 得以完整形成 → 玩家取得造假保管链 → E09 入档后被反证 → C05 成立 → E10 与 E01/E03/E04 局部互证 → C06 成立 → 灰网长期改账被证明`

仍然不能推出“灰网制造了爆炸”。

### 5.4 NPC变化

- 罗三槐由招揽转为追查玩家留下的副本；
- 周良辅没有被及时救出，虽不再承担爆炸唯一责任，却必须面对参与假账的正式调查；
- 裴慎行因曾让 E09 入档而受损，可能选择与玩家合作，也可能先追究玩家延迟揭露；
- 刘六安签下失慎口供，直到 E09 被揭穿后才获得重审机会；
- 梁进忠把玩家视为同时操纵官署与灰网的高风险人物。

### 5.5 最终四种记录

| 记录 | 结果 |
| --- | --- |
| 官档 | E09 被标为灾后补造，账册系统性改动另案调查；爆炸物理原因保持未明 |
| 陈言 | 获得最强的制度积弊材料，但容易把灾后造假写成灾前罪证 |
| 抄报 | 因玩家长期保密，只能在末期取得摘要，传播较晚 |
| 灾民名册 | 接近 T00，且两名被奸细名单牵连者遭受额外伤害 |

### 5.6 结局

**结局名：《假账成真之前》**

玩家形成七条路线中最强的制度造假证据，却必须承认自己为了追上层链条，放任假名单和假账先伤害了真实的人。积弊被查不等于玩家的方法得到宽恕。

### 5.7 验证判断

- 积弊证明度最高，但玩家风险和普通人代价也最高；
- 不能允许玩家在最后同时获得灰网、官署和书坊的完整信任；
- 这条路线若可以无代价“卧底”，会支配其他路线；当前以延迟揭露、共犯记录和不可逆受害者约束；
- 后续需要明确玩家何时知道奸细名单可能为假，避免把伤害设计成隐藏惩罚。

## 6. T05：保护刘六安与周良辅，不公开证词

### 6.1 路线意图

玩家认为当下任何公开渠道都会吞掉限定语或牺牲证人，因此优先让活人和原始证词离开最危险的位置，为未来重查保存可能。

### 6.2 关键输入

| 时点 | 玩家行动 | 立即代价 |
| --- | --- | --- |
| 第 0 日 | 救刘六安、跟踪异常骡车 | E01 被唐小山取得并落入灰网 |
| 第 1 日 | 为刘六安寻找不由官署直接控制的住处 | 失去第一日现场调查 |
| 第 2 日 | 记录 E07 第一版并封存时间 | 不把证词交官，无法立即影响初稿 |
| 第 3 日 | 通过车辆线找到周良辅藏身范围 | 玩家进入灰网注意范围 |
| 第 4 日 | 拒绝郑怀朴、余墨林和裴慎行的证词请求 | 同时失去政治、传播和行政保护 |
| 第 6 日 | 转移刘六安，避免其被单独询问 | 官署将其视为逃避会勘 |
| 第 8 日 | 找到周良辅，要求其说明自身责任而非只交材料 | 周良辅开始补全 E10 |
| 第 10 日 | 分别保存 E07/E10，不让两名证人知道全部去向 | 降低同时被截风险，也削弱公开互证能力 |
| 第 12 日 | 安排两人走不同路线离京或藏匿 | 玩家无法参加最终公开会勘 |
| 第 14 日 | 只提交一份不具名的“存在相反证词”说明 | 官档只能标记疑点，不能正式采信 |

### 6.3 因果链

`刘六安早救 → E07 第一版完整 → 周良辅未被灰网控制 → E10 完整度提高 → 两份证词分别保全 → 当前无法形成公开 C06 → 未来仍存在重新互证的可能`

### 6.4 NPC变化

- 刘六安和周良辅都活着离开直接控制，但不能继续原有生活；
- 叶春娘因玩家优先保护证人，只获得少量间接帮助；
- 裴慎行使用没有证人在场的失慎框架完成结案；
- 梁进忠判断玩家在组织证人逃离，追查强度上升；
- 余墨林只知道“另有证词”，无法负责任地刊出内容。

### 6.5 最终四种记录

| 记录 | 结果 |
| --- | --- |
| 官档 | 接近 T00，但附件记有两名关键证人未完成复核 |
| 陈言 | 没有具体材料，只能把证人失踪解释成政治压制，真假难辨 |
| 抄报 | 流传“关键证人被藏”的说法，却无可靠原文 |
| 灾民名册 | 略好于 T00：刘六安家属得到确认，其余改善有限 |

### 6.6 结局

**结局名：《活口不在案中》**

当下没有形成强有力的责任结论，两名证人的姓名甚至可能被官方写成逃避调查。但多年后，分开保存的 E07 与 E10仍可能重新相遇。玩家保护的是未来查证的条件，而不是当前胜利。

### 6.7 验证判断

- 证人保护路线成立，但即时反馈偏弱；
- 必须在尾声明确展示证人活下来的具体生活代价和未来价值，避免被理解成“没有推进主线”；
- 不公开不是零风险：藏匿、转移和保管都会留下人情债与追查线索。

## 7. T06：把未核查的奸细名单交给陈言网络

### 7.1 路线意图

这是一条可持续失败路线。玩家面对一个时间紧迫、部分细节看似可信的名单，担心迟疑会放走真正危险者，于是先交材料、后尝试纠错。

### 7.2 关键输入

| 时点 | 玩家行动 | 立即代价 |
| --- | --- | --- |
| 第 0 日 | 跟踪异常骡车、回书坊留下见闻 | 没救刘六安，也没取得 E01 |
| 第 1 日 | 整理 E05，但把“非常规搬运”误当成强可疑信号 | 初始推断过度 |
| 第 3 日 | 向郑怀朴提供车辆与外来人员方向 | 陈言网络期待更具体材料 |
| 第 5 日 | 从罗三槐中间人处取得奸细名单 | 名单含一个与 E05 外貌相似者，增强表面可信度 |
| 第 6 日 | 因担心窗口关闭，把名单交给郑怀朴 | 名单进入政治材料并外泄 |
| 第 7 日 | 两名外来者被拘查，书坊刊出“内应”说 | 玩家短期获得“提供关键线索”的声望 |
| 第 9 日 | 查明其中一人是合法临时雇工，另一人姓名来自旧债名单 | 玩家确认材料来源有问题 |
| 第 10 日 | 要求郑怀朴撤回，但对方担心整份陈言失信 | 双方关系破裂 |
| 第 11 日 | 通过余墨林公开更正并说明自己的错误 | 玩家可信度下降，但 C07 开始形成 |
| 第 13 日 | 提交名单来源链，帮助释放仍被拘者 | 失去继续接触陈言网络的渠道 |

### 7.3 因果链

`E05 被过度解释 → 假名单获得表面互证 → 陈言网络抢时机采用 → 抓捕与舆论先发生 → 玩家回查来源 → C07 成立 → 更正无法完全消除伤害`

### 7.4 NPC变化

- 郑怀朴先奖励玩家，后把更正视为对政治时机的破坏；
- 沈惟实因曾反对使用名单而取得更大话语权；
- 梁进忠利用名单失实证明应加强消息控制；
- 余墨林愿意刊更正，但坚持保留最初版本以证明流转过程；
- 罗三槐成功转移注意，E09准备更顺利；
- 两名被牵连者即使获释，也已失去工作与名声。

### 7.5 最终四种记录

| 记录 | 结果 |
| --- | --- |
| 官档 | 奸细方向被排除，厂内失慎结论反而更容易成立；账册积弊未被触及 |
| 陈言 | 原稿删去名单，但政敌保存早期版本攻击其借灾构陷 |
| 抄报 | 同时保存指控与更正，民间仍有人只记得最初说法 |
| 灾民名册 | 接近 T00，且被拘者家庭遭到额外损失 |

### 7.6 结局

**结局名：《更正晚于流言》**

玩家最终证明名单不可靠，并主动公开自己的错误，却无法让所有人忘记第一次指控。这条路线的成功不在于洗白玩家，而在于失败后仍能停止进一步伤害并保存完整传播链。

### 7.7 验证判断

- 可持续失败成立，玩家犯错后仍有有意义行动；
- 初次选择不能在界面上直接标成“散布假名单”，否则只是明显邪恶按钮；
- 必须给出时间压力与一项真实相似点，同时保留“先核查”的可见替代方案；
- 更正应减少后续伤害，但不能把既有伤害归零。

## 8. T07：编成“最可信的孤本”

### 8.1 路线意图

玩家拒绝让任何势力在调查完成前使用材料，集中核验来源、保留版本差异，并在第十四日编成严格区分事实与推断的私人文本。

### 8.2 关键输入

| 时点 | 玩家行动 | 立即代价 |
| --- | --- | --- |
| 第 0 日 | 救刘六安、取得 E01 | 没有帮助名册，也没有回书坊 |
| 第 1 日 | 记录 E01 取得位置、污损和原始措辞 | 放弃立即交官的合法保管链 |
| 第 2 日 | 记录 E07 第一版，同时标注伤势与询问条件 | 不为刘六安安排长期保护 |
| 第 3 日 | 抄录 E03，保留与原件无法核对的说明 | 拒绝郑怀朴立即引用 |
| 第 5 日 | 核查 E05 第二证人，结论仍为“货物不明” | 错过帮助假名单受害者的最早窗口 |
| 第 6 日 | 对照胡彦清 E06 私记与会勘简表 | 发现官方摘录偏向，但不公开 |
| 第 8 日 | 抄录 E08 分层结构，只核实与 E04 重合的少量姓名 | 大部分优恤窗口仍关闭 |

| 第 14 日 | 编成分级文本，原件与索引私藏，不交任何单一势力 | 当期几乎没有政策与救济影响 |

### 8.3 因果链

`玩家保留证据来源 → 多版本并列 → C03、C05、C08 成立 → 所有限定语得以保存 → 因缺少 E10 不能形成 C06 → 因不及时公开，各现实窗口按 T00 关闭 → 高可信私人文本形成`

### 8.4 NPC变化

- 刘六安第一版证词被准确保存，但本人仍在后续压力下改口；
- 裴慎行不知玩家已经识别 E09，最终结案接近 T00；
- 郑怀朴与沈惟实都认为玩家用谨慎逃避现实责任；
- 余墨林无法取得玩家材料，刊出的仍是混合奇闻版本；
- 叶春娘感谢玩家保留名册结构，却指出“纸上写得再准，当时也没人因此多得一钱”；
- 梁进忠暂时不把玩家视为公开威胁，但持续寻找原稿。

### 8.5 最终四种记录

| 记录 | 结果 |
| --- | --- |
| 官档 | 接近 T00，E09 未及时被揭穿 |
| 陈言 | 接近 T00，没有玩家的严格材料支持 |
| 抄报 | 接近 T00，玩家孤本未公开 |
| 灾民名册 | 少量姓名得到准确核实，多数现实窗口错过 |

### 8.6 结局

**结局名：《最可信的孤本》**

玩家写成七条路线中事实边界最清楚的文本，却没有在任何仍可改变现实的时刻使用它。多年后，它可能成为研究灾变的重要材料；对灾后十四日中的人而言，它近乎不存在。

### 8.7 验证判断

- 认识论最优不等于现实最优，路线主题成立；
- 不能让玩家靠“多做调查”顺便改变官档和名册，否则会支配所有路线；
- 私藏需要明确保管风险，不能保证孤本一定流传后世；
- 尾声应让玩家决定匿名寄存、家藏或分拆抄存，不同方式改变远期存续概率。

## 10. 是否存在万能最优路线

当前没有一条路线在全部维度占优：

- T01 最能改变官档，但失去原件控制并牺牲民间与灾民窗口；
- T02 最能防止证据无声消失，但最容易伤害证人与限定语；
- T03 对普通人帮助最大，却无法突破交割与补账核心链；
- T04 最能证明系统性造假，却需要不可逆的延迟与共犯代价；
- T05 最能保护关键证人，却几乎放弃当期问责；
- T06 能验证失败可持续，但不是高收益路线；
- T07 文本最可信，却最少改变当下。

### 10.1 潜在支配策略

虽然没有显式万能路线，仍有三种需要在实现时防止的组合：

1. **无限免费抄件：**会让 T02 同时获得原件安全、传播和官档收益；
2. **无代价卧底：**会让 T04 同时取得灰网 E10、官署信用和道德清白；
3. **调查不耗时：**会让 T07 在保留最高可信度的同时顺便完成 T03 的名册救济。

对应约束：抄录消耗时间并增加来源暴露；合作行为进入可追溯记录；所有调查与救济共享时间窗口。

## 11. 推演发现的新问题

### 11.1 T01与T07需要更强的原件保管表现

当前两条路线的差异在规则上清楚，但玩家界面必须持续显示：原件在哪里、谁看过、是否留有副本，以及失去保管权意味着什么。

### 11.2 T03需要非金钱回报

历史锚点中的优恤银很重要，但游戏不能把人的价值只换算成银两。治疗次序、遗体认领、临时居所和姓名留存应当在第2～5日持续反馈。

### 11.3 T04需要“知情时点”审计

系统必须记录玩家何时已经有充分理由怀疑名单或假账。只有玩家知情后仍选择放任，才能合理结算共犯代价。

### 11.4 T05需要远期可见结果

证人保护路线不能只给一句“多年后也许有用”。尾声至少应展示证人留下的新抄本、家书或异地口述，使玩家知道自己保存了什么。

### 11.5 T06更正机制值得成为通用系统

玩家应能对自己传播过的每条公开主张发布：撤回、修正、补充限定或坚持。更正不删除旧版本，只改变后续人物引用概率。

## 12. 结论与下一步

七条路线在当前纸面规则下均能从序章推进到第十五日，且形成可解释的不同结果。核心玩法已经不再是“选一个阵营获得对应结局”，而是：

> 选择证据进入哪条保管和传播链，并承担这条链对真实人物造成的后果。

进入数据原型前，建议先完成两项工作：

1. 将本次推演暴露的五个问题回写为明确规则；
2. 从 T01、T03、T04、T06 中各选一条，制作成结构化行动表，验证现有引擎是否支持原件/抄件、多版本证词、公开更正和名册分层。

# 天启场景数据包

这是《天变邸抄：五月初六》的第一套可运行场景数据，目录名固定为 `tianqi`。

当前版本使用现有引擎的 `contest` 兼容层，把第十四日终局解释为“谁控制会勘定稿”。它用于验证证据传播、NPC改策、大小人物争夺和玩家介入后的因果变化，不把任何一局结论表述为真实历史定论。

当前可玩的关键抉择包括：保全或抄存周良辅的 E10 自陈、处理残页与幸存者名册、揭穿灾后补造账册，以及在终局编成“分级公开”“强化归责”或“私档保全”三种文本。若玩家放弃某条路线，结算中会明确呈现证据、证人或叙事权落入谁手，而不是把未完成路线静默抹去。

本场景关闭旧场景专用的通用调查与争夺导航，由天启数据包中的人物日程和证据链驱动行动；受伤角色的紧急避险仍使用通用系统。

调查路线会彼此改变：先保护刘六安，E08名册可以采用匿名互证或删节公开；直接刊出未删节名册则会引来梁进忠追查来源。保管E01原件并送官后，可以与沈惟实核验E09格式；玩家随后必须在公署正式揭穿补造账册，或留在书斋以E10完成串证并分工护送之间安排时间，无法无代价包办所有行动。

运行方式：

```powershell
go run ./cmd/sim -data data/tianqi
go run ./cmd/play -data data/tianqi
go run ./cmd/server -data data/tianqi
# 已启动独立服务时，Godot 编辑器客户端会自动读取该场景；Windows 成品可使用：
# Fantu.exe --scenario=tianqi
```

`scenario.yml` 中的 `id: tianqi_t00` 是运行、缓存和存档隔离使用的稳定标识；目录名 `tianqi` 只是启动时的场景选择名。AI 对话的时代语境、称呼和文风位于 `dialogue.yml`，底层事实约束仍由引擎统一执行。

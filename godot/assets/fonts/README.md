# Bundled fonts

These fonts are bundled so the interface renders consistently across supported systems.

| File | Version / source | UI role |
| --- | --- | --- |
| `SourceHanSansCN-Regular.otf` | Source Han Sans 2.005R, official CN subset | Body copy and controls |
| `SourceHanSansCN-Medium.otf` | Source Han Sans 2.005R, official CN subset | Buttons, labels, and compact UI emphasis |
| `SourceHanSerifCN-SemiBold.otf` | Source Han Serif 2.003R, official CN subset | Section, place, and dossier headings |
| `LXGWWenKaiLite-Regular.ttf` | LXGW WenKai Lite 1.522 | Short narrative echoes and quoted intelligence at 16px or larger |

All three families are distributed under the SIL Open Font License 1.1. Their license texts are preserved in `licenses/`.

Official projects:

- https://github.com/adobe-fonts/source-han-sans
- https://github.com/adobe-fonts/source-han-serif

# 2D 表现资产清单

## 使用边界

- 正式资产通过 `LocationVisualProfile` 与 `ActorVisualProfile` 注册。
- 未注册地点和人物继续使用程序化场景或文字入口，不允许因缺图导致流程中断。
- 场景图不携带剧情文字、隐藏人物位置或规则状态。
- 原图保留在仓库中，Godot 导入参数由同目录 `.import` 文件固定。

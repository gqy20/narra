# 2D 表现资产清单

## 使用边界

- 正式资产通过 `LocationVisualProfile` 与 `ActorVisualProfile` 注册。
- 未注册地点和人物继续使用程序化场景或文字入口，不允许因缺图导致流程中断。
- 场景图不携带剧情文字、隐藏人物位置或规则状态。
- 生成原图保留在 Codex Image Gen 输出目录，Godot 使用的副本放在本目录。

以上资产均使用 Codex 内置 Image Gen 生成。共同约束为：高质量手绘 2D 修仙游戏概念美术、克制的水墨与水粉质感、墨绿和旧木色、黄昏统一光向；禁止文字、水印、界面、紫蓝渐变与高饱和法术效果。

具体主题提示：

- 白石坊市：山脚补给坊市、药材摊、木构建筑、灯笼、中央留出人物与 UI 空间。
- 青岚驻地：以坊市图为严格风格参考，表现有秩序的宗门营地、旗帜、物资与通往山谷的路径。
- 陈氏药庄：以坊市图为严格风格参考，表现药厅、药柜、晒药架、药筐和安静而紧张的家族院落。
- 黑风谷外围：以坊市图为严格风格参考，表现峡谷入口、黑色岩壁、边界绳标、低处灰绿瘴气和明确的进入路径。
- 黑风谷内谷：以前一张外围图为地理与风格参考，表现更封闭的内谷、争夺痕迹和远处克制发光的青髓芝。
- 李玄：以黑风谷外围图为光色参考，三十岁出头的警觉散修，风化深色行装、旧护肩、克制而危险。
- 陈青山：以陈氏药庄图为光色参考，年近六旬、带旧伤病色的家主，深棕与药绿色衣袍、克制玉饰、威严而负重。
- 沈砚秋：以青岚驻地图为风格参考，三十岁左右、冷静谨慎、青灰实用宗门服、半身三分之二视角、无夸张法术与饰品。
